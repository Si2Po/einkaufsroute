Über diese App

Einkaufsroute · Stand November 2026

Ein Hobbyprojekt

Einkaufsroute ist ein privates Hobbyprojekt. Die App ist kostenlos, ohne Werbung und wird nebenbei weiterentwickelt.

Die Nutzung geschieht auf eigene Verantwortung und ohne Gewähr: Es kann Fehler geben, und es kann sein, dass es die App irgendwann nicht mehr gibt. Speichere deshalb ab und zu eine Sicherung (Einstellungen → Konto und Gruppen → Daten sichern und übertragen).

Wo deine Daten liegen

  • Auf deinem Gerät: Die App speichert alles im Browser-Speicher deines Geräts, damit sie auch ohne Netz funktioniert.
  • Bei Supabase (Datenbank, Server in der EU, Frankfurt), nur wenn du ein Konto hast: deine E-Mail-Adresse, dein Passwort (nur verschlüsselt), deine Listen, Essen, Geschäfte, Kategorien und die Kaufhistorie für die Vorschläge.
  • Bei GitHub Pages (GitHub, USA) liegt die App selbst. Beim Laden sieht GitHub technisch deine IP-Adresse, wie bei jeder Webseite.

Es gibt kein Tracking, keine Werbung, keine Analyse-Werkzeuge und keine Weitergabe an Dritte.

Wer was sieht

  • Was in deiner Gruppe „Persönlich“ liegt, siehst nur du.
  • Was in einer gemeinsamen Gruppe liegt, sehen alle Mitglieder dieser Gruppe.
  • Wer einen Teilen-Link zu einer Liste hat, sieht genau diese eine Liste, bis der Link beendet wird.
  • Der Betreiber dieser App könnte technisch in die Datenbank schauen. Das passiert nur, wenn du um Hilfe bittest, z. B. bei einem vergessenen Passwort.

Konto löschen

Unter Einstellungen → Konto und Gruppen → Konto löschen löschst du dein Konto selbst. Dabei werden deine E-Mail-Adresse, dein Passwort und alles in „Persönlich“ entfernt. Gemeinsame Gruppen bleiben für die anderen Mitglieder bestehen; bist du das letzte Mitglied, wird die Gruppe mit gelöscht.

Du hast außerdem das Recht auf Auskunft, Berichtigung und Löschung deiner Daten. Schreib dazu einfach an die Adresse unten.

Selbst betreiben

Der Code ist offen: github.com/Si2Po/einkaufsroute. Mit der Anleitung im Ordner supabase kann sich jeder kostenlos eine eigene Kopie einrichten (GitHub Pages + Supabase, beides im kostenlosen Tarif). Dann liegen die Daten nur bei dir.
